## 📋 Descripción
Sistema de recomendación de perfumes desarrollado para perfumerías 
como Fetiche. El sistema analizara las preferencias de los usuarios 
para sugerir fragancias personalizadas basándose en familias 
olfativas, intensidad y ocasión de uso.

## 🎯 Problema que resuelve
Muchos clientes tienen dificultades al elegir un perfume por 
desconocimiento de familias olfativas y cómo cada fragancia 
interactúa con características individuales como el pH de la piel.
